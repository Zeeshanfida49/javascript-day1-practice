# JavaScript Day 1 Practice

A responsive webpage built for my Week 2, Day 1 JavaScript assignment at Tech SG Studio.

The project presents JavaScript tasks through a browser interface so reviewers can enter values and view results directly.

## Tasks

### 1. Introduce Yourself
- Enter a name, age, city, skill, and student status.
- Generate an introduction using a template literal.
- Display each variable's JavaScript data type using `typeof`.

### 2. Shop Bill Calculator
- Enter prices and quantities for a notebook, pen, and bag.
- Calculate item totals and the subtotal.
- Apply a 5% discount.
- Apply 17% GST to the amount after discount.
- Display a clear customer bill.

With the default values:
- Subtotal: PKR 1000.00
- Discount: PKR 50.00
- Amount after discount: PKR 950.00
- GST: PKR 161.50
- Final total: PKR 1111.50

### 3. Converters and String Utilities
- Convert Celsius to Fahrenheit.
- Clean email text using `trim()` and `toLowerCase()`.
- Check for `@` using `includes()`.
- Check for a `.com` ending using `endsWith()`.
- Calculate a number's square as a bonus task.

The email checks demonstrate string methods; they are not complete email validation.

## How to Run
1. Download or clone this repository.
2. Keep the project files in the same folder.
3. Open `index.html` in a browser.

Alternatively, open the folder in VS Code and run `index.html` using Live Server.

No additional packages or build commands are required.
